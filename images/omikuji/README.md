# おみくじの画像

`/おみくじ` は `drawing.gif` を表示し、約3秒後に抽選結果の PNG へ切り替えます。
GIF は640×400、20 fps、3秒で、ループしません。
アニメーションを自動再生しない Discord の設定でも、結果は返信のテキストで確認できます。

画像はこのリポジトリ用に Canvas の図形と同梱フォントで描画しています。
外部の画像サービスや素材を使わず、Bot の実行時には生成しません。

リポジトリのルートから、既存の依存をインストールした環境で再生成できます。

```sh
mise exec -- pnpm exec ts-node scripts/generate-omikuji-assets.ts
```

運勢名、色、メッセージ、演出時間の定義は `src/features/omikuji/fortunes.ts` にあります。
変更した場合は画像を再生成して、スクリプトや定義と一緒にコミットしてください。
